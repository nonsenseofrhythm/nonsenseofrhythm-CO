# Nonsense of Rhythm — 서체 규정 (확정 2026-08-19)

이 문서가 서체에 관한 **최신 원본**이다. 지침서·규격서의 서체 항목과 어긋나면 이 문서를 따른다.
적용 범위: 웹사이트 · 앱 · 영상 · 인쇄물 · 소셜 · 실물 — **전부.**

## 원칙

```
로고 마크        Inter          — 바뀌지 않는다
그 밖의 모든 영문  Helvetica Neue LT Pro
모든 한글         Pretendard
```

## 1. 로고 마크 — Inter 유지

「Nonsense of Rhythm」·「nine dots」 워드마크와 아홉 점 마크는 **Inter로 고정한다.**

```
파일     01_Brand/Fonts/ 의 Inter v3.019 (Google Fonts 4.x 금지)
굵기     NoR 워드마크 Bold(700) · nine dots 앱 워드마크 SemiBold(600)
자간     −11.667%em  (tracking_px = −0.11667 × size)
```

⚠️ 이미 배포된 산출물이 이 자간 위에 서 있다 — 앱 임베드, 앱 아이콘,
유튜브 배너, 릴스 전편, 바람막이 자수 도면, 앱스토어 스크린샷.
**마크를 다른 서체로 바꾸는 것은 그 전부를 다시 만드는 일이다.** 지금은 하지 않는다.

## 2. 그 밖의 영문 — Helvetica Neue LT Pro

섹션 제목 · 라벨 · 버튼 · 내비게이션 · 본문의 영문 · 자막 · 캡션.

```
출처     Adobe Fonts (Monotype) · Creative Cloud 계정에 14종 설치됨
데스크톱  일러스트레이터·포토샵·프리미어에서 바로 사용
웹       Adobe Fonts 웹 프로젝트 「nonsenseofrhythm」 (2026-08-19 개설)
         <link rel="stylesheet" href="https://use.typekit.net/rez7jaf.css">
CSS 이름  "helvetica-neue-lt-pro"        (본문·제목)
         "helvetica-neue-lt-pro-cond"   (장체 — 필요할 때만)
```

⚠️ **킷에는 400과 700만 있다.** 600(SemiBold)은 없으므로 쓰지 않는다.
쓰면 브라우저가 가짜로 굵게 만들어 조판이 흐려진다.
로고 마크의 SemiBold는 Inter이므로 무관하다.

⚠️ 데스크톱 동기화와 웹 사용은 **별개의 허락**이다. 폰트 파일을 서버에 직접
올려 배포하는 것은 라이선스 위반이다 — 반드시 위 킷 링크로만 쓴다.

## 3. 한글 — Pretendard

본문·라벨·자막 전부. 한자는 Pretendard에 없으므로 Noto Sans CJK KR로 폴백한다.

```
앱      base64 임베드 (서브셋) — CDN 금지
웹      같은 도메인에서 제공 · Adobe Fonts 킷과 함께 쓴다
```

## 4. CSS 스택

```css
/* 로고 마크 */
font-family:'NoR Inter',sans-serif; letter-spacing:-.11667em;

/* 그 밖의 전부 */
font-family:'HelveticaNeueLTPro','Helvetica Neue','NoR P',-apple-system,sans-serif;
```

## 5. 숫자

앱 UI 안의 숫자는 SF Pro (tabular-nums). 그 외 숫자는 §2를 따른다.
